# STAGEMERCH — prototype

Vroege versie van de paginabouwer van STAGEMERCH: een plek waar artiesten hun eigen
merch ontwerpen en verkopen via een eigen artiestenpagina.

Alle artiesten, bands en productnamen in dit prototype zijn verzonnen; de beelden zijn
tijdelijke vullers. Dit is een schets om feedback op te verzamelen, geen werkende winkel.

Live te bekijken: https://philipcanoy.github.io/stagemerch-prototype/
